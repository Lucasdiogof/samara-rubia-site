# Samara Rúbia — Fisioterapia Pélvica (site)

Site institucional estático (Next.js export) hospedado em Cloudflare Workers Static Assets.
Identidade **Cacau & Baunilha**. Versão de revisão: **indexação desativada** até a aprovação do conteúdo.

```bash
npm install
npm run dev      # http://localhost:3000
npm run check    # lint + typecheck + build estático
npm run deploy   # build + wrangler deploy (requer wrangler login)
```

- Dados e contatos: `src/config/site.ts`
- O que falta confirmar: `docs/CONTENT_PENDING.md`
- Arquitetura, design system, animações e publicação: `docs/DOCUMENTATION.md`
